# PHP / 1С-Битрикс / Bitrix24 разработчик

Веб-разработчик с коммерческим опытом: разработка, доработка и поддержка проектов на **PHP, 1С-Битрикс, Bitrix24 и WordPress**.

Основное направление: backend, компоненты и инфоблоки, каталоги, интеграции через REST API, автоматизация бизнес-процессов в CRM. Плюс frontend, адаптивная вёрстка и оптимизация существующих проектов. Разбираюсь в сложном легаси-коде и довожу задачи до результата. AI-инструменты использую для ускорения работы, но решения проверяю сам.

**Открыт к удалённой работе** по Битриксу и Bitrix24. Telegram: [@usman_kamayl](https://t.me/usman_kamayl)

## Технологии

**Backend:** PHP 8, MySQL, REST API, AJAX, обработчики событий, Composer

**CMS и CRM:** 1С-Битрикс (компоненты, инфоблоки, каталоги, доработка функциональности), Bitrix24 (CRM, смарт-процессы, автоматизация), WordPress

**Frontend:** HTML5, CSS3 / SCSS, JavaScript (ES6+), jQuery, БЭМ, адаптивная вёрстка по макетам Figma

**Инструменты:** Git, Vite, Webpack, Gulp, Figma

**Дополнительно:** техническое SEO, Core Web Vitals, Schema.org, Google Analytics и Яндекс.Метрика, UTM-разметка
